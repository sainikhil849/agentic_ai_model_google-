# BookMyShow Venue Extraction - Quick Summary

## What Was Changed

### Enhanced `_extract_bookmyshow_venue_dom()` Method
**Location**: `agents/platforms.py` (BookMyShowAgent class)

**Improvements Made**:
```
TIER 1: Direct test-ID attributes
  └─ [data-testid="eventVenue"], [data-testid="venue"], [data-testid="venueName"]

TIER 2: Regex pattern matching on page text
  └─ "Venue: {name}", "Location: {name}", "Event Location: {name}"

TIER 3: Extract from specific containers
  └─ event-info, detail sections, article, role='region'
  └─ Filter for "venue", "cinema", "theater" keywords
  └─ Extract with smart regex patterns

TIER 4: JSON-LD script tag parsing
  └─ Extract structured venue data from embedded JSON-LD

TIER 5: Cinema name pattern recognition
  └─ Recognize: PVR, INOX, Cinepolis, Big Cinemas, Carnival, Miraj, Prasad
  └─ Recognize: Theater, Auditorium, Hall, Cinema patterns

TIER 6: Class-based CSS selectors
  └─ [class*='venue'], [class*='location'], [class*='cinema']
```

### Enhanced `_enrich_event_details()` Method
**Additional Feature**: Page title extraction as last resort
```
Page Title: "Standing Up By Kunal Kamra @ PVR Cinemas - BookMyShow"
           ↓
Extract: "PVR Cinemas"
```

## How It Works (Flow)

```
1. Page loads → Wait for networkidle + 1.5 seconds

2. Try TIER 1 (test-ID attributes)
   ↓ Found? Return venue ✓
   ↓ Not found? Continue...

3. Try TIER 2 (Regex on full page text)
   ↓ Found? Return venue ✓
   ↓ Not found? Continue...

4. Try TIER 3 (Container extraction)
   ↓ Found? Return venue ✓
   ↓ Not found? Continue...

5. Try TIER 4 (JSON-LD parsing)
   ↓ Found? Return venue ✓
   ↓ Not found? Continue...

6. Try TIER 5 (Cinema name patterns)
   ↓ Found? Return venue ✓
   ↓ Not found? Continue...

7. Try TIER 6 (Class-based selectors)
   ↓ Found? Return venue ✓
   ↓ Not found? Continue...

8. FALLBACK: Extract from page title
   ↓ Found? Return venue ✓
   ↓ Not found? Return None → Display "Not specified"
```
